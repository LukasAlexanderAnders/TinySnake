Brief description: 
Control the snake and use the up, down, left and right arrow keys to guide it towards the tortoise. As soon as it reaches the tortoise exactly, the snake grows. 
Warning: If the snake hits a wall or its own tail, the little adventure ends and you’ll have to start again from the beginning. 
Try to make the snake as big as possible and beat the HIGHSCORE. Have fun!

## Play
**Windows:** Download `TinySnake.exe` from the (https://github.com/LukasAlexanderAnders/TinySnake/releases) page and double-click it.
If Windows shows a warning, click "More info" and then "Run anyway".

**With Python:** `python main.py`

Highscores are saved automatically in `%APPDATA%\TinySnake`.
